# 보완 크롤링 실행 가이드 (kosis_meta_enricher.py)

> 트리(`kosis_table_tree.json`)의 표 목록을 읽어, 표마다 KOSIS `getMeta`로
> **차원·항목·시점·단위**를 보강한다. 결과는 `data/kosis_table_meta_v2.jsonl`.
> 전체 265,094표 기준 약 60시간 (분당 200건 제한, 표당 2~3회 호출).

---

## 0. 실행 전 준비물 (각자 로컬에서 최초 1회)

각 참여자가 자신의 컴퓨터에서 아래를 준비한다.

| 항목 | 방법 |
|---|---|
| **KOSIS API 키** | [kosis.kr 공유서비스](https://kosis.kr/openapi/) 에서 **각자 개인 키 발급** → 프로젝트 최상위에 `.env` 파일 만들고 `KOSIS_API_KEY=발급키` 입력 |
| 입력 데이터 | `data/kosis_table_tree.json` (96MB) 을 프로젝트 `data/` 폴더에 넣기 |

> ⚠️ **API 키는 반드시 각자 개인 키를 쓴다.** 분당 200건 제한이 키 단위라, 같은 키를
> 여러 명이 동시에 쓰면 모두 막힌다 (자세히는 4번 참고).
>
> ⚠️ `.env` 와 `kosis_table_tree.json` 은 git에 올라가지 않는다(용량·보안). 팀에서 별도로
> 공유받아 직접 넣는다. **API 키는 화면 캡처·채팅·클라우드 업로드 금지.** 노출되면 즉시 재발급.

---

## 1. 기본 사용 순서

### ① 소규모 테스트 (먼저 이걸로 동작 확인)
```
venv\Scripts\python.exe src\kosis_meta_enricher.py --limit 5
```
`성공 5 실패 0`이 나오면 정상.

### ② 전체 크롤링 시작
```
venv\Scripts\python.exe src\kosis_meta_enricher.py
```
- 출력: `data\kosis_table_meta_v2.jsonl`
- 진행 로그가 50건마다 표시된다.
- 약 60시간 소요.

### ③ 진행 상황 확인 (다른 터미널에서, 크롤링 안 멈춤)
```
venv\Scripts\python.exe src\kosis_meta_enricher.py --status
```
`status: running / completed / aborted`와 완료 건수를 보여준다.

### ④ 중단 후 재개 — 같은 명령을 그대로 다시
```
venv\Scripts\python.exe src\kosis_meta_enricher.py
```
- 이미 받은 표는 자동으로 건너뛰고 이어서 진행한다(체크포인트).
- **처음에 붙인 옵션은 재개할 때도 똑같이 붙인다** (예: `--categories A`로 시작했으면 재개도 `--categories A`).

---

## 2. 중단·재개(체크포인트) 동작

- 표 하나를 받을 때마다 파일에 즉시 저장(flush)하고, 100건마다 체크포인트 파일을 갱신한다.
- 컴퓨터가 꺼지거나 창을 닫아도 **그 시점까지는 보존**되고, 재실행하면 이어진다.
- 체크포인트 파일: `data\kosis_table_meta_v2.jsonl.checkpoint.json`
- 연속 20건 실패하면 자동 중단(API 장애·키 문제 판단). 원인 해결 후 재실행하면 이어진다.

---

## 3. 실행 중 지킬 것 (60시간 방치)

| 항목 | 이유 |
|---|---|
| 컴퓨터 절전 끄기 (전원 설정 → 절전 "안 함") | 절전 들어가면 크롤링이 멈춘다 |
| 터미널·VS Code 창 닫지 않기 | 닫으면 크롤링도 종료된다 |
| 인터넷 유지 | 끊기면 재시도하지만 오래 끊기면 중단될 수 있다 |
| 같은 API 키로 다른 곳에서 동시 실행 금지 | 분당 200건 제한이 **키 단위**라 나눠 쓰면 둘 다 막힌다 |

## 4. 여러 명이 나눠서 크롤링 → 합치기

**전제: 각자 다른 KOSIS API 키를 쓴다.** (같은 키로 동시 실행 시 분당 제한에 함께 걸림)

### 나누기 — `--categories`로 대분류 분담 + `--output`으로 파일 분리
지역통계(V)가 전체의 60%라 시간이 크므로, V를 한 명이 전담하고 나머지를 나누는 것을 권장.

```
# 사람1 (키1) — 지역통계 전담
venv\Scripts\python.exe src\kosis_meta_enricher.py --categories V --output data\meta_p1.jsonl

# 사람2 (키2) — 앞쪽 절반
venv\Scripts\python.exe src\kosis_meta_enricher.py ^
  --categories A,B,C,D,E,F,G,H1,H2,I1,I2,J1,J2 --output data\meta_p2.jsonl

# 사람3 (키3) — 뒤쪽 절반
venv\Scripts\python.exe src\kosis_meta_enricher.py ^
  --categories K1,K2,L,M1,M2,N1,N2,O,P1,P2,Q,R,S1,S2,T,U --output data\meta_p3.jsonl
```

전체 대분류 30개: `A B C D E F G H1 H2 I1 I2 J1 J2 K1 K2 L M1 M2 N1 N2 O P1 P2 Q R S1 S2 T U V`
(겹치지 않게 나누기만 하면 된다.)

### 합치기 — jsonl은 "한 줄 = 표 하나"라 이어붙이면 끝
```
# Windows PowerShell
Get-Content data\meta_p1.jsonl, data\meta_p2.jsonl, data\meta_p3.jsonl |
  Set-Content -Encoding utf8 data\kosis_table_meta_v2.jsonl
```
대분류가 겹치지 않으면 중복도 없다. (합친 뒤 `table_key` 중복·건수 검사 권장.)

## 5. 주요 옵션 정리

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--output <파일>` | 출력 파일 지정 | `data/kosis_table_meta_v2.jsonl` |
| `--categories A,B` | 특정 대분류만 | 전체 |
| `--limit N` | 이번 실행 최대 N개 | 제한 없음 |
| `--status` | 진행 상황만 출력 | — |
| `--skip-unit` | 단위(UNIT) 크롤 생략(더 빠름) | 단위 포함 |
| `--always-unit` | 단위 있어도 UNIT 항상 호출 | 조건부 호출 |
| `--max-per-min N` | 분당 최대 호출 수 (상한 200) | 180 |
| `--per-category N` | 대분류마다 랜덤 N개 표본 추출 | — |
| `--dump-raw` | 응답 원본 출력(검증용, `--limit`과 함께) | — |

## 6. 전체 파이프라인 (입력 → 출력)

이 가이드가 담당하는 범위는 **① 메타 보강 → ② 카탈로그 빌드**까지다.
(이후 벡터 색인 단계는 별도 담당.)

```
kosis_table_tree.json                (입력: 표 목록)
        │
        ▼  ① kosis_meta_enricher.py   ← 표마다 getMeta로 차원·항목·시점·단위 보강
        │
kosis_table_meta_v2.jsonl      (중간 산출: 표별 메타)
        │
        ▼  ② kosis_catalog_builder.py  ← 검색용 문서(doc_meta_text/doc_item_index) 생성
        │
kosis_catalog_v2.jsonl         (최종 산출: 검색용 카탈로그)
```

### 단계별 입출력

| 단계 | 실행 | 입력 | 출력 |
|---|---|---|---|
| ① 메타 보강 | `venv\Scripts\python.exe src\kosis_meta_enricher.py` | `data\kosis_table_tree.json` | `data\kosis_table_meta_v2.jsonl` |
| ② 카탈로그 빌드 | `venv\Scripts\python.exe src\kosis_catalog_builder.py --only-enriched` | `data\kosis_table_meta_v2.jsonl` | `data\kosis_catalog_v2.jsonl` (+ `_manifest.json`) |

### 각 파일이 담는 것

| 파일 | 내용 |
|---|---|
| `kosis_table_tree.json` | 표 목록: `org_id, tbl_id, 표이름, stat_id, 카테고리경로` (표가 무엇이 있나) |
| `kosis_table_meta_v2.jsonl` | 위 + **차원·항목·시점·단위** (표 안에 무엇이 들었나) |
| `kosis_catalog_v2.jsonl` | 위를 검색용으로 가공: `doc_meta_text`(임베딩용), `doc_item_index`(BM25용), 필터용 메타 |

> 여러 명이 나눠서 ①을 돌렸다면(4번), 합친 `kosis_table_meta_v2.jsonl` 하나로 ②를 한 번만 돌리면 된다.
