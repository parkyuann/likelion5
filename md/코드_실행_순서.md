# 실행 매뉴얼: raw 데이터에서 HCX·KOSIS 검색 실험까지

작성일: 2026-07-16

모든 명령은 프로젝트 루트 `C:\\news_verification`에서 PowerShell로 실행한다.

## 0. 준비

`.env`에 `KOSIS_API_KEY`와 `HCX_API_KEY` 또는 `NCP_CLOVASTUDIO_API_KEY`를 준비한다.

```powershell
.\\venv\\Scripts\\Activate.ps1
python -m pip install -r requirements.txt
```

## 1. raw → 전처리 → claim 추출

원천 파일은 `data/raw/AI_기반_뉴스_사실검증_시스템_프로젝트_데이터.csv`에 둔다.

```powershell
.\\venv\\Scripts\\python.exe src\\news_preprocessor.py
.\\venv\\Scripts\\python.exe src\\claim_extractor.py
```

산출물: `data/news_preprocessed.csv` → `data/claim_listform.csv`

## 2. schema v1 변환

```powershell
.\\venv\\Scripts\\python.exe src\\convert_claim_listform_to_schema.py
```

산출물: `data/claims_v1.jsonl`, `data/claims_v1_mappings.jsonl`. 초기에는 gold table mapping이 없어 mapping 파일이 0행일 수 있다.

## 3. KOSIS tree 및 catalog

tree가 없을 때만 API crawler를 실행한다.

```powershell
.\\venv\\Scripts\\python.exe src\\kosis_tree_crawler.py
```

그 다음 검색용 catalog를 만든다.

```powershell
.\\venv\\Scripts\\python.exe src\\build_kosis_catalog.py
```

산출물: `data/kosis_table_tree.json`, `data/kosis_org_names.json`, `data/kosis_catalog_v1.jsonl`, manifest. 동일 표는 `table_key=org_id:tbl_id`로 통합된다.

## 4. retrieval silver 입력 및 라벨

```powershell
.\\venv\\Scripts\\python.exe src\\create_retrieval_eval_set.py
.\\venv\\Scripts\\python.exe src\\label_retrieval_eval_codex.py
```

산출물: `data/retrieval_eval_claims_v0.csv`, `data/retrieval_eval_claims_v0_codex.csv`. Codex 결과는 silver이며 표 ID·차원·항목은 사람 검토 전까지 gold로 사용하지 않는다.

## 5. 평가셋 생성

```powershell
.\\venv\\Scripts\\python.exe src\\create_evaluation_sets.py
```

산출물: `data/evaluation/pilot120.csv`, `validation300.csv`, `final500.csv`, `evaluation_sets_manifest.json`. 세 셋은 `article_idx`가 서로 겹치지 않는다.

- `pilot120`: HCX 오류·출력 형식 확인
- `validation300`: 상태·claim class·기관 범위 층화 및 Codex/Claude 비교
- `final500`: 사람 gold label과 최종 지표 계산

## 6. 1차 HCX 파일럿

먼저 50건 smoke test를 실행한다.

```powershell
.\\venv\\Scripts\\python.exe src\\hcx_claim_experiment.py `
  --input data/evaluation/pilot120.csv `
  --limit 50 `
  --model HCX-003 `
  --temperature 0.0 `
  --top-p 0.8 `
  --prompt-version claim-observation-v1 `
  --input-cost-per-1m 0 `
  --output-cost-per-1m 0
```

문제 없으면 `--limit 50`을 제거해 120건 전체를 실행한다. 결과는 `output/hcx_experiments/<experiment_id>/`의 `cache.jsonl`, `predictions.csv`, `metrics.json`과 `data/hcx_experiment_metrics.jsonl`에 기록된다.

## 7. validation·final 실행

6단계 명령에서 `--input`만 각각 `data/evaluation/validation300.csv`, `data/evaluation/final500.csv`로 바꿔 실행한다. final은 사람 gold label 입력 후 실행한다.

## 8. offline retrieval baseline

```powershell
.\\venv\\Scripts\\python.exe src\\retrieval_harness.py
```

결과는 `data/retrieval_candidates_v0_codex.jsonl`이다. gold table mapping 전에는 후보 생성만 확인하고, gold 확정 후 Recall@5/10/20/50, MRR, nDCG를 산출한다.

## 원칙

raw → preprocess → claim extraction → schema → silver labeling → HCX pilot → human gold → retrieval 평가 순서를 지킨다. API는 smoke test 후 전체 실행하며, silver를 gold로 간주하지 않는다.
