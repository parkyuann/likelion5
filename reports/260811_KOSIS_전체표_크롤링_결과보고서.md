## 0. 결론 세 줄

1. 공유서비스 개발가이드에 게재된 **공식 통계목록 11개 뷰를 전수 크롤**하고 지표 경로로 뷰 밖 표 2건을 회수해, 중복 제거 후 **유니크 통계표 287,673건**을 확보했다. KOSIS 공식 총량 **289,906건의 99.2%**이며, 잔여분은 KOSIS 관리자 공식 답변으로 **"KOSIS 스스로도 열거 불가한 미등록 표"**임이 확인됐다(§5).
2. 기존 수집분(`MT_ZTITLE` 단일 뷰, 265,094건)은 **KOSIS의 한 단면**이었다. 작성중지통계·기관별·국제·북한·광복이전 등 **10개 뷰를 놓치고 있었고**, 이번에 신규 22,587건을 회수했다.
3. 전 뷰 **크롤 실패 0건**, 조용한 유실 감시(audit) 통과. 블루스크린 2회에도 체크포인트·원자적 저장으로 **데이터 손실 0**.

## 3. 데이터 신뢰성 검증

### 3.1 완전성 — 크롤이 끝까지 내려갔나

전 11개 뷰가 **대기큐 0 · 실패 0 · 실패로그 없음**으로 완주했다. 대기큐 0은 "더 탐색할 노드가 없다 = 트리 바닥까지 도달"을 뜻한다.

조용한 유실 감시(audit) 결과:

| 감시 항목 | 합계 | 판정 |
|---|---|---|
| `vw_cd_mismatch` (뷰 응답 오류) | 0 | ✅ |
| `skipped_visited` (경로 누락) | 0 | ✅ |
| `unknown_rows` (알 수 없는 행) | 0 | ✅ |
| `empty_nodes` (빈 노드) | 41 | 정상 빈 노드 (아래) |

`empty_nodes` 41건(BUKHAN 5·STOP 35·OTITLE 1)은 "자식이 없는 정상 노드"다. 작은 뷰 10개는 **재크롤 2회를 대조해 완전 일치**를 확인했으므로, 이 빈 노드가 일시적 오류가 아님이 검증됐다.

### 3.2 큰 뷰 상호 검증 — OTITLE ↔ ZTITLE

`MT_OTITLE`과 `MT_ZTITLE`은 재크롤 대조를 하지 않았으나(각 1회, 2.5시간+ 소요), **서로가 서로를 검증**한다. 둘은 같은 국내통계를 다른 축으로 담은 뷰다.

```
ZTITLE 266,424 | OTITLE 266,400 | 교집합 266,399
ZTITLE 에만 25건 | OTITLE 에만 1건 (차이 26건, 0.01%)
```

한쪽에서 `err 30`이 표를 통째로 삼켰다면 다른 뷰에는 남아 차이가 수천 건으로 벌어졌을 것이다. **26건뿐**이라는 것은 양쪽 다 유실 없이 완주했다는 강한 증거다. 그 26건은 KOSIS 원본에서 한쪽 목록에만 등록된 표들이다(크롤 오류 아님).

### 3.3 장애 복구

크롤 도중 **블루스크린 2회** 발생. 매번 다음으로 손실 없이 복구:
- 리프는 발견 즉시 append, 체크포인트는 200콜마다 저장
- 재개 시 체크포인트 이후 리프를 자동 절삭(`[TRUNC]`) 후 재수집
- 원자적 파일 쓰기(temp→replace)로 반쯤 쓰인 파일 없음

실측: 마지막 블루스크린 시 282줄이 체크포인트를 앞섰고, 재개 시 정확히 절삭 후 재채움 → **순손실 0**.

## 4. 뷰 간 중복 구조

한 통계표가 여러 뷰에 동시 등록된다(예: 실업률 표 = 주제별 '노동' + 기관별 '국가데이터처' + 대상별 '청년').

| 등장 뷰 수 | 표 수 | 성격 |
|---|---|---|
| 1개 뷰만 | **21,245** | 그 뷰 아니면 못 찾는 고유 표 (작성중지·국제·북한 등) |
| 2개 뷰 | 264,645 | 대부분 (주제별 + 기관별) |
| 3개 뷰 | 1,714 | |
| 4개 뷰 | 67 | |

```
555,945 (뷰별 단순 합)
− 268,274 (중복 등장분)
= 287,671 (유니크 표)
```

**1개 뷰 21,245건**이 핵심이다 — 기존처럼 `MT_ZTITLE` 하나만 긁으면 이 표들을 통째로 놓친다. 뉴스 팩트체크에서 "북한 인구", "일제강점기 통계", "작성중지된 옛 통계" 류 주장의 검증 후보가 여기 있다.

## 5. 뷰 밖 표 — 지표 경로로 2건 회수, 나머지는 KOSIS도 열거 불가 (공식 확인)

### 5.1 지표 티커 전수 조사

통계주요지표 코드표(XLS, 1,473개 지표명)를 KOSIS 검색에 넣어 상단 티커의
`generator_htmlLink(orgId, tblId)` 를 파싱했다(`probe_indicator_tables_v5.py`, API 키 불필요, 16분).

```
지표 1,473개 전수 → 표 255개 발견 → 그중 트리 밖 2개
  301:DT_731Y001  주요국 통화의 대원화환율  (일별, 1964~현재, 15개+ 통화)
  301:DT_038Y001  외환보유액
```

두 표는 마스터에 추가했다(`view_codes: ["INDICATOR"]`, 287,671 → **287,673건**).
`DT_731Y001` 은 원/엔·원/위안 등 **다통화 최신 환율의 유일한 출처**다 — 대체 표(`DT_036Y` 계열)는 전부 2014년 작성중지됐다.

### 5.2 원인과 잔여 규모 — KOSIS 공식 답변 (2026-08-11)

공유서비스 Q&A로 문의한 결과, 관리자 공식 답변으로 다음이 확정됐다:

> - 13건 외 통계목록(`MT_PTITLE`·`MT_ATITLE01/02`·`MT_ETITLE` 등)은 **"서비스 및 최신화가 진행되지 않는 통계목록으로 사용하지 않으면 되는"** 것들이다.
> - `주요국 통화의 대원화환율`은 **"통계목록에 지정되지 않은 주요 지표"**다.
> - **"목록에 달려있지 않은 통계표들이 더 존재할 수 있으나 (KOSIS) 서비스 기능으로는 확인이 어렵다."**

즉 잔여 약 2,233건은 **KOSIS 스스로도 열거하지 못하는 미등록 표**다. 외부에서 발견할 접점(트리·검색·지표) 자체가 없으므로, 지표 경로로 회수한 2건이 실질적 최대치다. 이 답변으로 보류 뷰 3종(`MT_PTITLE`·`MT_ATITLE01/02`)의 **영구 제외도 공식 근거를 얻었다** (계획서의 P2' 판정 완료).
