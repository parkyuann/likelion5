## 상세 — doc_meta_text 토큰 분포

임베딩되는 필드는 `doc_meta_text` 하나뿐이다 (`doc_item_index`는 BM25 전용이라 임베딩 안 함).

|---|---|---|
| 평균 | 48.6 | 68.5 |
| 중앙값(p50) | 48 | 68 |
| p90 | 62 | — |
| p99 | 72 | — |
| **최대** | **77** | 109 |

- **최대 토큰 표**: `시군구별 체류기간별 외국인 주민현황(계)` — 77 토큰
- 최대치가 한도(8,192)의 **약 0.9%** 수준. 여유가 100배 이상.

## 한도 기준

| 항목 | 값 | 출처 |
|---|---|---|
| HCX 임베딩 v2 입력 한도 | **8,192 토큰** | 공식 문서(임베딩 v2) |

| 초과 표 | **0건** | — |

## 비고

- 토큰 수는 **추정치**다. 글자 수 ÷ 1.41(자/토큰, 임베딩 API `inputTokens`로 실측한 비율)로 계산했다. 정밀값이 필요하면 색인 시 API가 돌려주는 `inputTokens`로 대체 가능하나, 여유가 100배라 실용상 불필요.
- **분리 설계의 효과**: 차원값(예: 읍면동 6,000여 개)을 `doc_item_index`로 빼지 않고 합쳤다면 최대 46,000자를 넘겨 한도를 초과했을 표가 나온다. 차원명만 `doc_meta_text`에 남긴 결과 초과율이 0%가 됐다.
- 이 지표는 **표본(515건)** 기준이다. 전체 265,094건 크롤링·재빌드 후 같은 스크립트로 재산출 예정.
