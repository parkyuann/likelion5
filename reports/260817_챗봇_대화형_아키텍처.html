세션 저장 규칙

  • 근거 저장: 분석 파이프라인이 후보5·판정을 저장 (새 기사일 때만)
  • 히스토리 저장: 최종 답변 텍스트를 저장 (매 턴)
  • 읽기: 오케스트레이터가 매 턴 히스토리·근거를 읽어 후속/신규 판단
  • 기사 비교·과거 기사 되돌아감 없음 → 캐시 슬롯 1개 덮어쓰기로 충분

재질의 구분

  • 새 분석 대상(이미지/URL/기사텍스트)이 들어오면 → 신규 → 파이프라인, 캐시 덮어쓰기
  • 짧은 텍스트 + 이전 결과 참조 → 후속형 → 캐시로 즉답
  • 이미지 등 origin은 분석 후 텍스트로 세션에 남으므로, 후속/신규 판단은 origin과 무관

HCX 제약 (주의)

  • function calling과 이미지입력 · structured output · thinking은 한 요청에 동시 사용 불가
  • → 이미지는 (HCX-005 비전 추출) + (분석) 2단으로 분리
  • function calling 지원 모델: HCX-005 / HCX-DASH-002 / HCX-007 (HCX-DASH-001·HCX-003 미지원)
