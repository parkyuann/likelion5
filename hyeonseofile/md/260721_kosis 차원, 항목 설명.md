# KOSIS API 통계표의 "차원"과 "항목" 정리

예시 통계표: **프랜차이즈통계(가맹점)** (`tblId = DT_FR0001N`)

---

## 1. 기본 개념

KOSIS의 통계표는 다차원 데이터(OLAP 큐브와 유사) 구조입니다. 값 하나를 정확히 지목하려면 여러 개의 분류 축(=**차원**)을 함께 지정해야 하며, 그 값이 "무엇을 측정한 수치인지"를 나타내는 것이 **항목**입니다.

| 구분 | 의미 | 이 표에서의 역할 |
|---|---|---|
| **차원(Dimension)** | 값을 특정하기 위한 분류 축 | 어느 지역, 어느 업종, 몇 년도 |
| **항목(Item)** | 그 위치에서 실제로 측정된 값의 종류 | 가맹점수, 매출액 등 |

---

## 2. 이 통계표의 차원

| 차원 | 화면상 명칭 | API 파라미터 | 값 예시 |
|---|---|---|---|
| 분류1 | 시도별(1) | `objL1` | 전국, 서울특별시, 부산광역시 ... |
| 분류2 | 주요 업종별(1) | `objL2` | 합계, 체인화 편의점, 한식 음식점업 ... |
| 시점 | 연도 | `prdDe` / `startPrdDe`~`endPrdDe` | 2023, 2024 |

---

## 3. 이 통계표의 항목 (`itmId`)

| 항목명 | 단위 |
|---|---|
| 가맹점수 | 개 |
| 종사자수 | 명 |
| 매출액 | 백만원 |
| 영업비용 | 백만원 |
| 매출원가 | 백만원 |
| 인건비 | 백만원 |
| 임차료 | 백만원 |
| 기타영업비용 | 백만원 |

- 여러 항목을 한 번에 조회하려면 `+`로 연결: `itmId=T1+T2+T3+T4`
- 전체 항목을 다 받으려면: `itmId=ALL`

---

## 4. 특정 셀 조회 예시

**"2024년 · 서울특별시 · 체인화 편의점"의 가맹점수**를 조회하는 경우

### 개념적 표현
```
차원: 시도별(1)     = 서울특별시
차원: 주요업종별(1)  = 체인화 편의점
차원: 시점          = 2024
항목(itmId)         = 가맹점수
→ 결과값: 8,812개
```

### API 호출 예시
```
https://kosis.kr/openapi/statisticsData.do?method=getList
&apiKey=발급받은키
&orgId=101
&tblId=DT_FR0001N
&objL1=11        ← 서울특별시 코드
&objL2=XX        ← 체인화 편의점 코드 (표별 확인 필요)
&itmId=YY        ← 가맹점수 항목 코드 (표별 확인 필요)
&prdSe=Y
&startPrdDe=2024
&endPrdDe=2024
&format=json
&jsonVD=Y
```

### 응답 예시 (JSON)
```json
[
  {
    "C1_NM": "서울특별시",
    "C2_NM": "체인화 편의점",
    "ITM_NM": "가맹점수",
    "PRD_DE": "2024",
    "DT": "8812",
    "UNIT_NM": "개"
  }
]
```

> JSON 응답은 화면처럼 항목이 가로로 나열된 표 형태가 아니라, **(지역 × 업종 × 시점 × 항목) 조합마다 레코드 하나씩** 세로로 나열되어 반환됩니다.

---

## 5. 참고

- `objL2`(업종 코드), `itmId`(항목 코드)의 실제 코드값은 통계표마다 다르게 부여되어 있습니다.
- KOSIS 사이트 → 해당 통계표 선택 → **"URL 생성"** 화면에서 분류/항목 체크박스를 선택하면, 해당 코드값이 자동으로 URL에 채워집니다.
- 통계표 메타정보(차원·항목 목록)는 아래 API로도 확인 가능합니다.
  ```
  https://kosis.kr/openapi/statisticsData.do?method=getMeta&type=TBL
  ```
