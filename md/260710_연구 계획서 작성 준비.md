- Background & Baseline
    - 기존에 연구들은 이 문제, 혹은 유사 문제에 대하여 어떻게 접근하였는가?(논문 리서치. 단, 논문 리뷰는 생략합니다)
        1. Wenhu Chen, et al. (2020). 「TabFact: A Large-scale Dataset for Table-based Fact Verification」. ICLR 2020.
           - 위키피디아 등의 '표(Table) 데이터'와 비교하여 이 수치적 주장이 참(Entailed)인지 거짓(Refuted)인지 판별하는 모델 메커니즘
        2. 한지은, 김은솔 (2023). 「텍스트 내 수치 정보의 맥락적 의미 추출 및 지식 베이스 변환 구조 연구」. 정보과학회 학술발표논문집.
           - 접근방법: 비정형 텍스트에서 "단순 숫자"가 아닌 "주장으로서의 수치적 의미"를 파싱(Parsing)하는 기술(문장 안에서 수치(예: 15.4)와 그것이 가리키는 대상(엔티티: 청년 실업률), 단위(%), 상태(증가/감소)를 묶어 하나의 구조화된 데이터(트리플 또는 엔티티 묶음)로 변환하는 개체명 인식(NER) 및 관계 추출 기술)
           - 우리 연구와의 연결방법: KOSIS API를 호출하기 전, 뉴스 기사에서 '무엇을 검색해야 할지' 파라미터 재료를 뽑아내는 전처리 단계에 활용
        
        수치적 사실 검증 이외의 문장검증 연구
        1. 이종혁 (2026). 「한국어 팩트체크 필요성 탐지 모델 및 RAG 기반 팩트체크 자동화 시스템 개발 : 대선 후보자 토론회 적용」. 한국언론학보, 70(2)
           - 접근방식: 텍스트 전체에서 "어떤 문장이 검증이 필요한 주장(Claim)인가?"를 탐지하는 데 초점을 맞춤, 자연어 처리 기술을 활용해 문장의 어조, 정치적 맥락, 선동성 등을 분석하여 자동으로 검증 우선순위를 매기는 방식
           - 차별점: 맥락상 '팩트체크가 필요한 문장인가'를 가려내는 데는 탁월하지만, 문장 속에 숨은 구체적인 통계 수치의 왜곡(예: 전년 대비 증감률 오류, 단위 혼동 등)을 정밀 연산하여 검증하지는 못함
      
        2. 이서영, 최성필 (2024). 「원문(full-text) 검색을 활용한 실시간 팩트 체크 시스템 구현」. 한국정보과학회 학술발표논문집.
           - 접근방식: 수집된 문서(PDF, 뉴스 등)에서 텍스트를 추출한 뒤, BERT 기반의 인코딩 모델을 활용해 기존에 검증된 레퍼런스 문서 풀(Pool)과 의미론적 유사도를 비교하는 방식(문장 벡터 비교를 통해 체크)
           - 차별점: 이 방식은 텍스트 대 텍스트(Text-to-Text) 비교에 의존 (<=> KOSIS api = '수치 대 수치'로 교차 검증)

        3. 오종환 (2021). 「한국어 자동화 팩트체크 기술과 활용: 데이터세트 작성과 기계학습 모델 구축」. 팩트체크 동향리포트 FACT.
           - 접근방식: 사전에 '정답(Ground Truth)' 역할을 하는 기계학습용 데이터세트를 정형화하여 구축하고, 이를 기반으로 입력된 주장의 진위를 판별하는 알고리즘, 지식 베이스를 규칙화(Rule-based)하거나 특정 도메인의 데이터셋을 미리 기계에 학습시켜 두는 방식
           - 차별점: '사전에 구축된 닫힌 데이터셋(Closed Dataset)' 안에서만 검증이 가능 (<=> 국가통계포털(KOSIS)의 Open API = '실시간 열린 데이터(Live Data)')

        4. 박민우, 이준호 (2025). 「거대 언어 모델의 외부 API 연동을 통한 사실성(Factuality) 개선 및 할루시네이션 방지 시스템 구현」. 지능정보연구, 31(1).
           - 목적: AI의 할루시네이션 방지를 위해
           - 접근방식: 모델이 직접 외부 검색 API나 특정 기관의 오픈 API를 호출(Tool-using)하여 그 결과로 답변을 보정하게 만드는 아키텍처 연구
           - 차별점: 국가 통계(KOSIS)"라는 아주 특수하고 복잡한 구조(세세분류, 시계열, 단위 코드 등)의 API에 특화되어 있지 않으므로 **수치 기반 주장**의 사실 여

    - 이번 프로젝트에서 사용할 baseline 모델
