## 부록. 미해결 이슈 상세 — 뷰 밖 표 ~2,233건 (멘토링/조사 대상)

**현상**: KOSIS 공식 통계표 289,906건 중 287,673건 확보. 약 2,233건이 어느 서비스뷰·검색
API·지표 목록에도 안 걸림. 단 tbl_id 를 알면 API 데이터는 정상 조회됨(표는 실재).

**시도한 것 (전부 실패)**: 11개 뷰 전수 / 통합검색 API / 통계주요지표 1,473개 티커(→2건만 회수)
/ tbl_id 무차별 대입(비현실적)

**KOSIS 공식 답변**: "목록에 없는 표가 더 있을 수 있으나 기관에서 실제 제공되는지 확인이
어려워 서비스로 제공 못 함" — 즉 KOSIS 자신도 열거 불가.

**관찰**: 못 찾은 표 상당수가 한국은행(org 301). KOSIS가 원천 통합 시 분류 누락한 것으로 추정.

**검토 방향**: (a) 한국은행 ECOS 등 원천 기관 직접 수집 (출처 이원화 트레이드오프)
(b) 0.8% 미수집을 완료로 볼지 (환율·외환보유액 등 뉴스 단골 표가 섞임)
